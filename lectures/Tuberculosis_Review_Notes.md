# Tuberculosis module review record

Version 1.1, September 15, 2026. The original publication record below describes version 1.0. The cross-module clinical and language review is documented in `Lecture_Review_2026-09-15.md`; the current module contains 36 references.

Scope: practical primer for residents and ID fellows, with an attending update pathway. Covers infection versus disease, pulmonary and extrapulmonary diagnostics, test discordance, mimics, latent TB treatment, susceptible and resistant disease, dosing and toxicity, special populations, and selected newer treatment data.

Format: follows the existing self-contained HTML lecture design. Includes five objectives, nine fictional cases, ten discussion questions with rationales, 35 linked references, and a printable one-page rounds summary. No external scripts, fonts or images are required for offline reading.

Evidence review: CDC, ATS/CDC/ERS/IDSA and WHO guidance were compared with the cited primary trials. Trial populations, endpoints, uncertainty intervals and limitations are identified. Abstract-only access for several newer trials is disclosed in the module. Investigational strategies are distinguished from guideline-supported care. This is not an exhaustive pipeline review.

Repository preparation, validation, eight existing behavior tests and RSS generation passed. Source links were inspected during research; no claim of a complete automated external-link audit is made.
